# 🔐 Random Password Generator

A simple Python application that generates strong random passwords using letters, numbers, and optional symbols.

## 📌 Features

- Generate passwords of any length
- Uses uppercase & lowercase letters
- Includes numbers
- Optional symbols
- Input validation
- Easy-to-use console interface

## 🛠️ Technologies Used

- Python 3
- random module
- string module

## ▶️ How to Run

```bash
python PasswordGenerator.py
```
