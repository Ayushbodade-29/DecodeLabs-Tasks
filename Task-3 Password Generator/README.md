# 🔐 Random Password Generator

A **Python command-line application** that generates random passwords using letters, numbers, and optional symbols.

Developed as part of my **DecodeLabs Internship**.

---

## 📌 Project Overview

The Random Password Generator demonstrates Python concepts such as **modules, string manipulation, random selection, loops, functions, and input validation**.

Users can specify the desired password length and choose whether to include symbols.

---

## ✨ Features

- 🔐 Generate random passwords
- 🔢 Include numbers
- 🔤 Use uppercase and lowercase letters
- 🔣 Optionally include symbols
- 📏 Generate passwords of any positive length
- ✅ Validate password length
- ⚠️ Handle invalid user input
- 🖥️ Simple command-line interface

---

## 🛠️ Concepts Used

- Python 3
- `random` module
- `string` module
- Functions
- Loops
- String manipulation
- Conditional Statements
- User Input
- Exception Handling

```text

     RANDOM PASSWORD GENERATOR
===================================

Enter desired password length (e.g., 8): 12
```
